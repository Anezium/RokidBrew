# Changelog

## v0.2.1 - 2026-05-31

- Fixed an immediate launch crash on EMUI 14 / Android 14 devices, reported on Huawei Mate XT.
- Guarded an Android 15-only frame-rate API so high-refresh behavior remains enabled only where the platform supports it.

## v0.2.0 - 2026-05-30

- Redesigned the RokidBrew store UI with richer app detail pages.
- Added the self-update screen with update badge, changelog, download, and install actions.
- Added selectable Rokid CXR-L host app support.
- Added phone and glasses install state tracking with update and uninstall controls.
- Refactored CXR-L app upload, query, and uninstall operations.
